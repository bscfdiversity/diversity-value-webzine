GitHub Desktop 업로드 방법
1. 이 ZIP 파일을 먼저 압축 해제합니다.
2. diversity-value-webzine 폴더 안의 index.html, README.txt, pages, videos, images, fonts를 모두 선택합니다.
3. GitHub Desktop에서 새 저장소를 만든 뒤 Repository > Show in Explorer로 저장소 폴더를 엽니다.
4. 선택한 파일과 폴더를 저장소 폴더에 붙여넣습니다.
5. Commit to main을 누른 뒤 Publish repository 또는 Push origin을 누릅니다.
6. GitHub 저장소의 Settings > Pages에서 main / (root)를 선택합니다.
7. index.html이 저장소 최상단에 있어야 합니다.

구동 방식
- 전체 54페이지
- 화면 오른쪽: 다음 페이지 / 화면 왼쪽: 이전 페이지
- 키보드 방향키와 모바일 좌우 스와이프 지원
- 오른쪽 위 메뉴 버튼: 목차 열기
- 5페이지 영상 썸네일 클릭: 스케치 영상 확대 재생
- 확대 영상 바깥 오른쪽 클릭: 다음 페이지
- 확대 영상 바깥 왼쪽 클릭: 이전 페이지
- ESC: 영상 또는 목차 닫기
